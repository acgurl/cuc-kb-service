# 证据级盲测 v3 线上评测报告（2026-11-14）


> 本报告是 v3 首轮结果。标注更正后的结果见 `report_evidence_v3_1.md`（v3.1：可答 hit@5 89%、correct 95%、fabricated 3.3%）。
纯评测，线上代码、配置、数据零改动。数据集 `dataset_evidence_v3.json`（281 题，12 类；214 可答 + 67 不可答），在 Phoenix 生产 API（`cuc_kb_v4`，展开 + 自适应版本降权 + 表格 caption 均已上线）上运行。

## 结论

1. **可答题检索：evidence_hit@1/3/5/10 = 116/169/188/201（54% / 79% / 88% / 94%）**，hit@5 的 95% 置信区间 83%–92%。
2. **可答题端到端（qwen-plus 读 top5 作答）：correct 196/214（92%），complete 158（74%），fabricated 10（4.7%），refused 5。**
3. **不可答题的结果目前不能直接采信**：检索层只拒掉 38/67，但逐题核对后发现 attribute_trap / partial 两类里有相当一部分题其实库里有答案，是标注问题而不是系统误接受（见「数据集问题」）。
4. 证据丢失的头号环节是**融合池截断**（15 项），其次是**证据排在第 6–10 位**（10 题）；召回缺失只有 3 项。
5. 0 次精排降级，延迟 P50/P95 = 1314/2435 ms。

v3 与 v2（34 题，@5 79%）是不同题集，数字不能直接对比。

## 数据集问题（建议先修再用作基线）

1. **attribute_trap / partial 的无答案标注不可靠。** 构建时只核验了探测短语零命中（如「研讨间预约电话」），没有核验所问事实本身是否存在。上面至少 8 题库里有答案。这两类共 41 题需要逐题复核。
2. **vc01 标准答案过时。** 标答是本科 16000 / 研究生 20000（2024-06 版说明），但库里有财教〔2024〕188 号和 2025、2026 版说明，现行额度是 20000 / 25000。模型答的 20000 / 25000 是对的，却被判错误加编造。
3. **cov02 标准答案存疑。** 标答取自 2006 年《优秀教学奖评选及奖励办法》（每年一次、15 名、5000/3000/1500），库里同时有中传人字〔2017〕208 号（每两年一次、18 名、2 万/1 万/5000），两份都是 active。模型选了 2017 版被判编造，需要人工确认哪份现行。
4. **部分短查询和问句欠限定**，系统答了另一个合理对象被判错：b16b09「违约几次进黑名单」（图书馆 vs 体育场馆）、b16b10「团体预约提前几天」（博物馆 vs 体育场馆）、b14b_07「MBA 学费多少」（标答是预科项目）、b1_01「缓考」（标答限研究生，问句未说）、b4b_01 / b4b_03（标答限 2026 年，问句未说年份）。
5. **判定噪声**：b13_10、b4b_05 检索未命中、模型如实拒答，judge 的理由却是「应基于常识/标准答案作答」。结论（未答对）没错，但理由不可用。

只修正 vc01 一题，可答题 correct 为 197、fabricated 为 9；cov02 若确认 2017 版现行，则为 198 和 8。

## 语料侧暴露的问题

- **过时文件仍是 active 且无标注**：2021 版贷款说明（8000/12000，vc01 中排 top1）、2006 版教学奖办法、2016 年留学生招生简章。现有 12 对替代关系覆盖不到这些「同名通知逐年更新」的情况。
- 2006 版教学奖办法的 `publish_date` 是 2019-04-27（网页日期），会让它看起来比 2017 版新。
- 招生域最弱（hit@5 8/12）：多年份简章并存，问句不带年份时容易混答。

## 口径说明

- LLM 作答与判定都是 qwen-plus 单次运行，temperature 0，未做多次取多数；v2 已见过同一上下文两次作答不同的情况。
- 端到端评测是「top5 原文一次作答」，不是生产 agent 的多问法、多轮读取流程。
- 不可答题补测的 judge 看不到检索原文，只看问题、标注说明和回答，所以会把「引用了库里真实存在的号码」判成编造；上面的逐题核对就是为了纠正这一点。
