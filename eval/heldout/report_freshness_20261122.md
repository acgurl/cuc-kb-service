# 新旧版本检索 A/B（2026-11-22）

**状态：候选未上线。** 生产 API、MCP、Open-LLM-VTuber、Qdrant 和语料未改；仅在 Phoenix 回环端口启动了基于同一份生产只读语料和索引的候选 API/MCP。

## 改动

- MCP 打开 `KB_MCP_PREFER_CURRENT=1` 时，由 `kb_search` 在内部给 REST 请求加 `prefer_current`；生产 REST 默认和对 Agent 暴露的工具参数不变。已明确废止的条款默认不参与当前证据；用户明确问历史年份、原文号或新旧对比时保留旧版。逐年重发与正式废止分开处理，不按发布日期全库排序。
- 对已经核验的本科国奖旧金额，`kb/clause_updates.json` 精确标记 6 个原文片段，包括 2026 汇编中转载的旧条款。对默认检索仅移除被替换的片段，不删除整份旧办法；纯旧条款可把已核验的新条款送入同一次精排，仍遵守 assistant / doc_type。相邻块展开不补回已移除的片段。原始 PDF 和全文读取保持不变。
- 历史文档的原文读取会透传 `superseded_by` / `newer_version`，以便显式查阅历史文档时保留版本提示。

两轮检索指标逐项一致。延迟结论仅为未观察到稳定的新增开销；15 题的 P95 近似取样本最大值，受网络抖动影响，不能据此认定稳定达成 2 秒门槛。

退化题 FR01：助学贷款旧版含「应届第二学士学位学生」，因匹配用户问句得分 0.9289，生产以前用它撑起了 direct。候选仍返回最新版说明，但最高相关分低于生产全局阈值，降为 related。不能用旧版置信度或直接下降全库阈值来补；后续应单独验证新版证据的判定、工具补查和最终答复。

HTTP MCP 实际工具调用验证：本科国奖现行检索已不包含已标注的旧 8000 元，能返回 10000 元；博士评阅不再返回已标记废止的 8 号旧版；明确点名 2022 年收费票据 134 号仍返回该文。这里只验证了工具结果，未把它计为 DeepSeek / Open-LLM-VTuber 最终答复提升。
